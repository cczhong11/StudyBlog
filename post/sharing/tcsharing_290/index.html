新闻思考

最近 AI 圈有两件事放在一起看特别有意思。

第一件是 OpenAI 的 Codex。自 GPT-5.6 Sol 发布以来，官方已经连续四次重置使用额度，开发者已经从一开始担心额度不够，变成了开始期待下一次 reset，大家可以几乎没有顾虑地一直用 AI 写代码。

第二件是 Kimi K3 的发布。它不仅进入了第一梯队，还在 Frontend Code Arena 上拿到了世界第一，让不少海外开发者开始重新审视中国大模型的实力。虽然综合软件工程能力还需要更多第三方验证，但至少在前端生成这个用户最容易感知的领域，它已经证明了自己的竞争力。

这两件事背后，其实反映的是同一个现象：AI 大模型已经进入了真正的用户争夺战。

这让我想起了十年前国内互联网最疯狂的那段时间。无论是团购大战、网约车大战，还是共享单车大战，各家公司都在疯狂补贴，因为当时没有任何一家能够完全统治市场，最重要的目标就是先把用户留在自己的平台。

今天的大模型竞争越来越有当年的味道。OpenAI 疯狂重置 Codex 的额度，Anthropic 不断调整 Claude Code 的套餐，Google、Kimi、DeepSeek 也都在持续降低使用门槛。原因其实很简单，目前还没有任何一家模型已经强到形成绝对领先。大家都在第一梯队，今天你领先一点，下个月别人可能就追上来了。在这种情况下，比起短期赚钱，更重要的是培养开发者的使用习惯，占据企业的 API 入口，以及建立自己的生态。

所以，现阶段最大的赢家其实是用户。模型越来越强，价格越来越低，额度越来越多，大家都在用各种方式争取开发者留在自己的平台。

不过，这场竞争也已经进入了后半场。两三年前，还有很多公司在自己训练基础模型，而今天真正还能持续投入数百亿甚至上千亿美元、拥有顶级算力和数据去训练下一代基础模型的玩家，其实已经越来越少了。越来越多的小公司开始放弃自研基础模型，转而基于 OpenAI、Anthropic、Google、Kimi、DeepSeek 等模型做应用层产品。牌桌上的玩家正在减少，但牌桌上的竞争却越来越激烈。

未来等市场格局逐渐稳定之后，这种疯狂送额度、不断补贴用户的情况大概率不会一直持续。所以至少现在，对于开发者来说，正是一个体验最好、成本最低的时代。趁着几家顶级 AI 公司还在疯狂抢用户，多用、多体验，也许几年之后回头看，这会是 AI 行业最“卷”、但也是用户最幸福的一段时间。
